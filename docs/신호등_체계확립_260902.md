## 1. 성능의 정의를 바꾸니 무엇이 달라졌나

지금까지의 비교는 집합 크기가 달라서(초록 3,158 vs 경보 뺀 1,614) 공정하지 않았다.
**날짜별 상위 K개 고정**으로 다시 재니:

- 초록 문턱은 순위와 무관하다 — greenAt 55~75 를 바꿔도 K20 성적은 한 줄도 안 변한다
  (6부 §3). 문턱은 **「하루에 몇 개를 보여 줄까」만 정한다.**
- 경보를 「초록에서 빼기」로 재면 +6.7 인데 K 고정으로 재면 +5.9 — 절반은 집합이 작아진
  효과였다. 그래도 +1.0%p 는 남고, 하방(-21 → -18)과 추락 비율(33 → 28%)이 같이 좋아진다.
- **고유 종목 수**가 처음으로 보였다: K20 을 81일 모으면 세대 3 은 304종목, S9 는 226,
  탈락 승격 뒤 192~238. 좁힐수록 같은 종목이 반복된다(연속 반복 53~60%). 하루 20개가
  실은 7~8종목의 며칠치일 수 있다 — 후보 수를 셀 때 이걸 같이 봐야 한다.

## 3. 최소 집합 — 정직하게

### 3-1. 뒤에서 하나씩 빼기 (전체 표본, K20 · 무게1 · 축1/1/1)

11개 +4.9 → −fgnRatio20 +5.4 → −overhead +5.7 → −flowPersist +5.6 → −flowAccel **+6.2** →
−shortLevel +5.9 → −ma5Gap +5.6 → −foreignRatioUp +5.0 → −newHigh +4.1.

전체 표본에서 고르면 7개(S7)가 최고다. **그런데:**

### 3-2. 한쪽 절반에서 고르고 반대쪽에서 채점

```
앞 절반에서 고름 → 뒤 절반 채점:   11개 +6.0 → −overhead +6.0 → −fgnRatio20 +6.2
                                  → −qYoY +4.3 ✗ → −flowAccel +5.6 → −flowPersist +5.0 → −shortLevel +3.8 ✗
뒤 절반에서 고름 → 앞 절반 채점:   11개 +3.5 → −flowAccel +3.1 → −newHigh +2.0 ✗ → −overhead +2.1 …
```

- overhead · fgnRatio20 은 어느 쪽에서 골라도 빼는 게 낫거나 같다 → **뺀다.**
- 그 다음부터는 **고른 쪽에서만 좋고 반대쪽에서 무너진다.** 앞(쏠림·급락)에서 고르면
  약세장 실적(qYoY)을 버리고, 뒤(반등)에서 고르면 강세장 신고가를 버린다 — 둘 다 반대
  계절에서 필요한 것이다. 이게 「7개가 최고」가 in-sample 인 이유다.

→ **S9 = 세대 3 − overhead − fgnRatio20.** 나머지 넷(수급 지속·가속·공매도 수준·5일선
이격)은 leave-one-out 에서 빼도 안 떨어지지만(±0.1) 반대쪽 절반 검증이 엇갈려 **12월까지 둔다.**

### 3-3. 왜 그 둘인가

- **외인 시총대비(fgnRatio20)**: 지분율 상승(foreignRatioUp)과 r=**0.80**, 외인+기관
  시총대비(flowRatio)와 0.48 — 같은 「외국인이 사고 있다」를 세 번 세고 있었고, 무게 2 라
  순위를 「외국인이 가장 많이 산 종목」 쪽으로 밀었다. 그 꼭대기는 이미 몰린 자리다
  (2부: 2%↑ 약세 -0.5). 2부에서 단독으로 가장 센 기준이었지만 **순위에서는 겹침이 독**이다.
- **위쪽 매물(overhead)**: 강세 전용 위험축. 빼도 K20 이 그대로이고, 이걸 빼면 장세
  전환 의존이 거의 사라진다(장세 끔 +6.2 → +6.1). 있을 때는 장세 끔이 +4.9 → +2.9 였다 —
  즉 이 기준이 「장세를 못 재면 도구가 망가지는」 취약점이었다.
