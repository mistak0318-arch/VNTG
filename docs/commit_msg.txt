AI 비용 집계 정확도·기능별 귀속, 웹 리서치 캐시, 시장 신호등

설정 화면의 추정 비용이 실제 청구와 안 맞았다. 네 군데가 틀렸다.

- 모델을 안 가리고 하루치 토큰을 한 덩어리로 더해 놓고, 단가는 calls 객체에서
  먼저 나온 모델 하나로 전부 계산했다. 리포트를 Opus 로 채널 요약을 Haiku 로
  돌리면 어느 쪽이 먼저 찍혔느냐에 따라 몇 배씩 어긋난다.
  이제 `기능|모델` 버킷에 나눠 담는다.
- 캐시 토큰(쓰기 1.25배 / 읽기 0.1배)을 아예 안 셌다.
- 웹 검색 건당 $0.01 이 통째로 빠져 있었다. 이게 제일 큰 누락이다.
- priceFor 의 폴백이 sonnet 이라 표에 없는 Gemini 모델이 Claude 단가로 잡혔다.
  이름으로 계열을 먼저 가른다.
- Sonnet 5 는 2026-08-31 까지 인트로 단가($2/$10)인데 표에 $3/$15 로 박혀 있었다.
  이것만으로 33% 과대계상. 날짜가 지나면 자동으로 정상가로 계산한다.

기능별 귀속을 붙였다 — 리포트 / 시황질문 / 채널요약 / 웹리서치 / 이미지인식.
호출 내역이 모델명만 나열하면 소용이 없다. "claude-sonnet-5 20회"만 봐서는
리포트가 쓴 건지 채널 요약이 쓴 건지 알 수 없다.
vision.ts 의 generateText 는 리포트·채널과 공유되는 경로라 feature 를 넘기지 않으면
그쪽 비용이 전부 "이미지 인식"으로 잡힌다 — 같이 막았다.
설정에 「AI 비용」 카드를 새로 뒀다. 하루치만 보면 "얼마 썼나"에 답을 못 하므로
보관 기간(30일) 누적을 메뉴별·모델별·일별로 보여준다.
옛 기록은 모델·기능을 가를 수 없어 「기타」로 잡히는데, 그 사실을 화면에 경고로
띄운다. 조용히 섞으면 왜 안 맞는지 영영 모른다.

돈이 새던 곳은 웹 리서치였다.

오늘 Claude 입력 토큰 1,918,526 중 대부분이 여기다(어제는 29,994). 리포트 본문
호출은 입력이 7,798 뿐이다. 서버사이드 web_search 는 검색 결과가 대화에 쌓이고
매 턴 재전송돼서 입력이 기하급수로 붇는다 — 한 번에 입력 96,000 토큰이 나왔다.
그런데 발행할 때마다 새로 돌리고 있었다. 간밤 미국장은 하루에 한 번 끝난다.

- 90분 캐시. 조간·장중·석간 세 판이 결과를 공유한다.
- 검색 횟수 조간 8→5 / 장중·석간 6→3 / 주말 4→2.
  횟수를 줄이면 재전송이 줄어 입력 토큰은 그보다 빠르게 준다.

리포트가 출력 상한에 걸려 잘리고 있었다. 상한을 올리지 않았다 — 프롬프트는
2,200자를 요구하는데 모델이 3배를 쓴 것이라 올리면 그만큼 더 나간다.
분량 제한을 강제 문구로 바꾸고, "표에 있는 숫자를 그대로 옮겨 적지 마라"를 넣었다
(화면에 이미 있는 값을 다시 쓰느라 분량이 샌다). 잘렸을 때는 마지막 성한 문장까지만
남긴다 — "코스닥 전기/전자(-1,9" 같은 반쪽 숫자가 남으면 오독한다.

텔레그램 AI 정리는 재 보니 하루 3회 · 약 $0.14 로 문제가 아니었다.
그래도 선별 60→40건, 본문 220→180자로 줄이고, 선별이 8건 미만이면 AI를 부르지
않는다 — 그 분량이면 원문 링크가 붙은 선별 목록이 오히려 낫다.

시장 전체 신호등 (서버).

종목 신호등은 "이 종목이 내 기준에 맞나"를 본다. 아무리 좋은 종목도 시장이
무너지는 날엔 같이 빠지므로, 고르기 전에 지금이 살 자리인지를 봐야 한다.
항목은 **지금 손에 있는 데이터의 깊이**로 골랐다. A/D 라인은 breadth.json 이 2일치뿐이고
백필이 안 되므로 여기 기대면 몇 달을 기다려야 한다.

- 지수 추세(ka20006 업종일봉) / 시장 폭 / 업종 확산 / 외국인·기관 5일 누적
- 지수는 ETF(069500) 대신 **지수 자체**를 쓴다. ETF 는 하루 고저 폭 20%, 회전율 17%
  로 찍히는 날이 있어 20일선 기울기를 태우면 추세가 아니라 잡음을 읽는다.
- 업종 등락률은 스냅샷을 업종별로 묶어 중앙값으로 낸다. ka10051 의 changeRate 는
  값을 안 채워 줘서 저장된 58일치가 전부 0이었다.
- 지수 추세가 판단 보류면 초록을 주지 않는다. 나머지가 다 좋아도 추세 미확인은
  대개 반등 국면이라, 그때 초록을 켜면 되돌림을 추세로 오해한다.
