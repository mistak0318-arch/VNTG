# 외부 접속 계획 — 회사에서도 보기

2026-08-20 수립. **구현 전에 이 문서를 다시 읽을 것.**

목표: 회사 PC(네이버 웨일 등)에서 미니PC의 VNTG HTS 를 **실시간으로** 본다.

---

## 0. 지금 상태 (사실 확인)

| 항목 | 현재 |
|---|---|
| 서버 | Express, `0.0.0.0:4000`, `web/dist` 정적 서빙 |
| 인증 | **없음** |
| CORS | `app.use(cors())` — **전면 허용** |
| 통신 | HTTP |
| `.env` | 키움·한투·네이버·DART·**텔레그램 봇 토큰**·**네이버 메일 비번**·Anthropic/Gemini/OpenAI |

**잘 돼 있는 것 하나** — `/api/settings/env` 는 키 값을 안 준다. `configured: true/false` 만 준다.
즉 **HTTP 응답으로 비밀이 새는 구조는 아니다.** 위험은 「비밀이 샌다」가 아니라
**「아무나 내 계좌·관심종목·복기노트를 본다」** 쪽이다.

---

## 1. 두 갈래 — 그리고 왜 한쪽을 고르는가

### A. 터널 (미니PC 그대로, 앞에 인증)

미니PC 가 Cloudflare 로 **바깥으로 연결을 건다.** 회사에서는 그 주소로 들어간다.

- ✅ **집 IP 가 노출되지 않는다.** 포트포워딩도 공인 IP 도 필요 없다 —
  들어오는 연결을 받는 게 아니라 **나가는 연결**을 유지하는 방식이다
- ✅ **실시간이다.** 미니PC 가 그대로 응답한다
- ✅ 코드 변경이 거의 없다
- ✅ 무료

### B. 클라우드로 데이터를 밀어 재구성

미니PC 가 주기적으로 데이터를 클라우드에 올리고, 회사에서는 클라우드를 본다.

- ✅ 미니PC 가 인터넷에서 아예 안 보인다
- ❌ **실시간이 안 된다.** 미는 주기만큼 늦다 — 호가창·체결강도·1초 갱신은 뜻을 잃는다
- ❌ **비밀이 두 곳에 생긴다.** 클라우드에도 내 계좌 잔고·관심종목·복기노트가 쌓인다.
  지금은 집 안에만 있는 것들이다. **미러링이 더 위험할 수 있다**
- ❌ 구현량이 훨씬 크다 — 밀어 넣는 파이프라인 + 클라우드 저장 + 클라우드 API + 인증을 전부 새로
- ❌ 무료 티어 제약(용량·실행시간·콜드스타트)을 계속 신경 써야 한다

### 결론: **A 로 간다**

「집 IP 노출이 걱정」이라는 이유로 B 를 고르려던 것인데, **A 도 IP 를 노출하지 않는다.**
그러면 B 의 유일한 장점이 사라지고 단점만 남는다.

> ⚠️ **B 가 맞는 경우도 있다.** 실시간이 필요 없고 **리포트·요약만** 회사에서 읽고 싶다면
> 그때는 B 가 낫다(미니PC 를 아예 안 열어도 되므로). 지금 목표는 실시간이라 A 다.

## 2. A 안 설계

```
[회사 PC] ──HTTPS──> [Cloudflare] ──터널──> [미니PC:4000]
                          │
                     인증 게이트
```

### 2-1. 터널 — Cloudflare Tunnel

- 미니PC 에 `cloudflared` 설치, 서비스로 등록(재부팅해도 살아 있게)
- 도메인이 필요하다. 없으면 Cloudflare 에서 하나 사거나(연 1~2만원) 무료 서브도메인 사용
- HTTPS 는 Cloudflare 가 자동으로 붙인다 — 인증서 관리가 없다

### 2-2. 인증 — 두 선택지

**(가) Cloudflare Access — 코드 0줄**
- Cloudflare 대시보드에서 「이 이메일만 허용」 설정
- 접속하면 이메일로 일회용 코드가 오고, 맞으면 통과
- **무료 티어로 충분하다**(50명까지)
- 우리 서버는 손댈 게 없다. 터널 뒤에 그대로 둔다

**(나) 직접 구현 — ID/PW + 텔레그램 코드**
- 이미 텔레그램 봇이 붙어 있어 **메일 SMTP 를 새로 안 붙여도 된다**
- 로그인하면 봇이 코드를 보내고, 그게 곧 2단계
- 세션 쿠키·CSRF·무차별 대입 차단을 **직접** 만들어야 한다

**권고: (가) 부터.** 보안 코드를 직접 짜는 건 틀리기 쉽고, 틀리면 조용히 틀린다.
Cloudflare Access 로 먼저 열고, 나중에 불편하면 (나) 로 바꾼다.

### 2-3. 서버 하드닝 (이건 어느 쪽이든 해야 한다)

1. **`app.use(cors())` 를 좁힌다.** 지금은 전면 허용이라, 서버가 인터넷에 닿는 순간
   내가 방문한 **아무 웹사이트나** 내 API 를 부를 수 있다. 터널을 쓰면 출처가 하나뿐이므로
   그 출처만 허용한다
2. **바인딩을 `127.0.0.1` 로.** 터널은 로컬로 붙으므로 `0.0.0.0` 일 이유가 없다.
   같은 공유기 안의 다른 기기에도 안 보이게 된다
3. **쓰기 엔드포인트 점검.** 조회 전용이라지만 설정·메모·관심종목은 **쓴다.**
   인증이 뚫리면 지워질 수 있는 것들이다 — `server/data` 백업 주기를 정한다
4. **`/api/settings/env` 는 지금처럼** `configured` 만. 값은 절대 싣지 않는다

## 3. 순서

| 단계 | 할 일 | 미니PC 필요 |
|---|---|---|
| 1 | CORS 좁히기 · `127.0.0.1` 바인딩 (환경변수로 켜고 끄기) | ✗ (코드) |
| 2 | `cloudflared` 설치 · 터널 등록 · 서비스 등록 | ✓ |
| 3 | Cloudflare Access 로 이메일 제한 | ✓ |
| 4 | 회사에서 접속 확인 | ✓ |
| 5 | (선택) 텔레그램 2단계로 교체 | ✗→✓ |

**1단계는 지금 할 수 있다.** 나머지는 미니PC 앞에 앉아야 한다.

## 4. 미리 정해 둘 것

- **도메인**: 있는 게 없으면 하나 필요하다. 어떤 이름으로 할지
- **허용 이메일**: Cloudflare Access 에 넣을 주소

### 회사 네트워크 — 무엇을 확인하나

**Cloudflare 자체가 막힐 가능성은 낮다.** 웹의 상당 부분이 그 뒤에 있어서 통째로 막으면
회사 업무도 안 된다. 진짜 걸리는 건 다른 쪽이다.

| 확인할 것 | 왜 | 막히면 |
|---|---|---|
| **개인 메일이 열리나** | Cloudflare Access 가 개인 메일로 OTP 를 보낸다 | **텔레그램 인증**((나)안)으로 |
| 금융·주식 사이트가 열리나 | 카테고리 차단이 흔하다. 새 도메인은 미분류라 더 걸리기 쉽다 | 도메인·카테고리 조정 필요 |
| Cloudflare 기반 사이트가 열리나 | 예: `discord.com` · `medium.com` | 계획 전체 재검토 |

**세 번째보다 첫 번째가 중요하다.** 개인 메일을 막는 회사는 흔하고, 그러면 이메일 OTP 를
못 쓴다.

⚠️ **확실한 판정은 터널을 실제로 띄워 봐야 난다.** 도메인 없이 `trycloudflare.com` 임시
주소로 5분이면 시험된다 — 다만 미니PC 앞에 앉아야 한다. 위 셋은 「미리 걸러내기」다.

### 확인 결과 (2026-08-20, 회사 PC)

| 확인 | 결과 |
|---|---|
| 개인 메일 | ✅ **열림** → 이메일 OTP 가능. (나)안(텔레그램)을 안 짜도 된다 |
| 네이버 금융 | ✅ 열림 → 금융 카테고리는 안 막힌다 |
| 쇼피파이 | ✅ 열림 → **Cloudflare 인프라는 통과** |
| 디스코드 | ❌ 막힘 |

**디스코드가 막힌 건 Cloudflare 때문이 아니다.** 쇼피파이가 열리는 게 증거다 —
둘 다 Cloudflare 뒤에 있는데 한쪽만 막혔으니 **카테고리 차단**(메신저/게임)이다.

→ **A 안 + Cloudflare Access(이메일 OTP)로 확정.**

### 남은 미지수 — 미분류 도메인

새로 만든 도메인은 필터에서 **「미분류」**다. 디스코드를 카테고리로 막는 걸 보면 이 회사
필터는 꽤 촘촘해서, 미분류를 막을 가능성이 있다. **도메인을 실제로 띄워야만 안다.**

막히면 두 갈래:
- 필터 업체에 **분류 요청** (보통 며칠)
- **이미 분류된 무료 서브도메인** 사용 (예: 흔한 동적DNS 제공자의 서브도메인)

⚠️ 도메인 이름에 `trade`·`stock`·`invest` 같은 말을 넣으면 자동 분류기가 엉뚱한 곳에
넣을 수 있다. **중립적인 이름**이 안전하다.

## 5. 하지 말 것

- **포트포워딩으로 여는 것.** 공인 IP 가 그대로 드러나고 스캐너에 바로 걸린다
- **인증 없이 잠깐만 열어 두는 것.** 「잠깐」이 길어지고, 그 사이 계좌 화면이 공개된다
- **비밀을 클라우드로 복사하는 것.** 지금 집 안에만 있는 것들이다
- **보안 코드를 급하게 짜는 것.** 틀리면 조용히 틀린다 — 다른 기능과 섞지 말고 따로 볼 것
