# 표식 근거 — 「이 종목은 왜」 (2026-09-08)

벤티지: "번개·신호등·무지개 여러 마크가 달리잖아. 마우스 올렸을 때 왜 그랬는지 알려 주고, 모바일에선 종목 상세 클릭하면 마크랑 간단한 설명."

## 표식 다섯과 문장 틀

| 표식 | 무엇을 재나 | 문장 |
|---|---|---|
| 🌟 슈퍼신호등 | 신호등 초록 목록 여러 개의 교집합 | `{N}개 목록 교집합({목록 한글 이름}) · 편입 때 {점수}점 · {편입일} 편입 뒤 {수익률} (5일 시장 대비 {초과})` |
| ⚡ 교차 | 슈퍼신호등 ∩ 그날 주도주 탐색 | `주도주 태그 {신고가·거래량급증…}({섹터}) ∩ 슈퍼신호등 — 주도주에서 빠지면 그날부터 안 붙는다` |
| 🌈 무지개 | 며칠째 계속 교집합인가 | `{N}일째 계속 교집합(문턱 {rainbowDays}일, 마지막 {날짜}) — 지속성` |
| ● 신호등 | 색·점수·이유 | `{점수}점 · 탈락: … · 통과: 상위 셋 · 걸림: 상위 둘 · (얇음/작음)` |
| 🔥 ⏳ 경보 | 쏠림·늦음 | 경보 라벨들 + 「몰린 자리는 고점이었던 계절(신조 ①체)」 |
| ★ 관심 | 사용자가 찍음 | `네가 {날짜}에 찍음({그룹}) · 편입가 · 메모` / 자동 그룹만이면 그렇게 |
| ⤴ 이탈 | 원장에서 나감 | `{날짜} 이탈 — {사유} · 이탈 5일 뒤 {수익률}` |

「좋다·사라」는 안 쓴다. 사실·문턱·시간만.

## 어디

- 서버 `markWhy.ts` → `GET /api/signal/super/why/:code`. 원장·관심종목은 파일, 신호등만 `evaluateSignal`(15분 캐시).
- `useSuperMarks.whyOf(code)` — `/api/signal/super` 응답(원장 + `listLabels`)에서 목록 화면용 툴팁을 만든다. 요청 0회. `SuperMark`의 `title`이 이걸 쓴다.
- `PriceHeader` `MarkChips` — 「종가 · 장 마감」 줄 아래 칩 줄. 누르면 한 줄 근거, 넓은 화면은 툴팁으로도. 표식이 없으면 줄을 안 그린다.
