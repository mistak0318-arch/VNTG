# 시장 흐름 분석 — 로직 재검토 (2026-08-25)

트레이더 빙의로 여섯 탭(맥박·주도주 탐색·일정 매매·종가배팅·자금 흐름·수출 동향)의
로직을 훑고, 오늘 실측값으로 동작을 확인한 기록. **구현 아이템은 맨 아래.**

## 오늘 실측으로 확인한 것

```
GET /api/pulse (2026-08-25 저녁)
  days=9  phase=개인 홀로 매수
  flow: 외인5일 -93,271억 · 기관5일 -31,387억 · 개인5일 +68,913억 · 외인 3일 연속 매도
  divergence: warn=False (지수 -1.82% / 폭 +43.8%p)
  turn: False · basis=null
  risks: 외국인 연속 매도
```

판정 자체는 맞게 돌았다 — 외인·기관 동반 매도 + 개인 매수 = 「개인 홀로 매수」,
연속 매도 3일이 warn 으로 잡혔다. 문제는 판정보다 **재료의 얇음과 표기**다.

## 탭별 점검

### 맥박 (marketPulse)

**잘 돼 있는 것** — 판정을 서버 한 곳에서만 하는 구조, 국면 6종 + 방향전환(누적 vs
최근 어긋남) + 다이버전스(지수 vs 폭) + 위험 문장화. 트레이더 입장에서 「결론 먼저,
이유 문장으로」 구조는 맞다.

**걸리는 것**
1. **20일 누적이 사실은 9일 누적이다.** 폭 데이터가 9일치인데 `slice(-20)` 으로
   계산해 「20일 누적」이라 적힌다. 라벨이 거짓말을 한다 — 며칠치로 계산했는지를
   라벨에 붙여야 한다 (「20일(9일치)」).
2. **폭(breadth)은 과거 백필이 안 된다** (당일 스냅샷 누적 방식). days=9 로는
   다이버전스·20일 국면이 전부 잠정이다. 화면이 days 를 보여주긴 하나, 판정 옆에
   「표본 9일 — 잠정」 배지가 더 정직하다.
3. **basis=null 이 조용히 사라진다.** 장 마감 후 선물 값이 없으면 백워데이션 위험이
   그냥 안 뜬다 — 「못 봤다」와 「정상이다」가 구분이 안 된다.
4. divergence 문턱(지수 +0.5% & 폭 -8%p)은 합리적이나 **5일 고정**이다. 데이터가
   쌓이면 10일 창도 같이 보는 게 꼭지 감지에 낫다.

### 주도주 탐색 (leaderScan)

구조 건전: 거래대금 상위 → 섹터 묶음 → 폭·가중/단순 분리 → 태그 → 15:35 자동 기록
→ 성적(leaderTrack). 「폭 70% 미만은 섹터가 아니다」 문턱도 문서와 일치.

**걸리는 것** — 성적과 신호등·슈퍼신호등이 **서로 모른다**. 같은 종목이 주도주 태그와
슈퍼신호등에 동시에 걸리면 그게 가장 강한 시그널인데, 지금은 사람이 두 화면을 오가며
눈으로 맞춰야 한다.

### 일정 매매 (eventPlay)

D0 기준 성적(소문에 사서 뉴스에 판다 검증)은 이 앱에서 가장 독창적인 부분. 로직 이상
없음. 다만 **일정 입력이 전부 수동**이라, 입력이 끊기면 탭이 죽는다 — 캘린더(이미
이미지 인식으로 받는 일정)와 반자동 연결이 다음 단계.

### 종가배팅 (closeBet)

486건 검증 → 「선물 양봉 + 반도체 대형주 + KRX 마감 + 시초 매도」 결론, 실전 추적은
장마감 시점 선물로 분리 — 방법론이 제일 단단한 탭. **다만 결론이 2026-08 시장에
고정**돼 있다. 시장 성격이 바뀌면(예: 반도체 주도가 끝나면) 결론이 낡는데, 그걸
알려주는 건 「전체 vs 최근 20일」 비교뿐이고 사람이 봐야 한다. 어긋나면 서버가
경고를 만들어 주는 게 맞다.

### 자금 흐름 (sectorFlow + breadth)

업종별 누적·연속·주체 합의·연기금 vs 투신 — 구성 좋음. 백필 120일도 있다.
**걸리는 것** — 규모별 자금 배분이 코스피만이고, 업종 흐름과 맥박의 국면 판정이
따로 논다(맥박은 시장 전체, 여기는 업종별 — 연결 문장이 없다).

### 수출 동향 (tradeStats)

이번에 나라별 월별 흐름까지 넣어 구조는 완성형. 남은 건 **주가와의 연결 검증** —
「수출이 꺾였는데 업종만 오르는」 경고를 자동으로 만들 재료(exportYoyForSector)는
이미 있는데 신호등/맥박 어디에도 안 얹혀 있다.

## 구현 아이템 (효과 순)

| # | 아이템 | 크기 | 내용 |
|---|---|---|---|
| 1 | **누적 라벨 정직화 + 잠정 배지** | 소 | 20일 누적을 실제 일수로 표기(「20일(9일치)」), days<20 이면 판정 옆 「표본 부족 — 잠정」 배지. basis null 이면 「선물 값 없음(장 마감)」 한 줄 |
| 2 | **교차 신호 한 줄** | 중 | 맥박 상단에 「주도주 태그 + 슈퍼신호등 + 업종 자금 유입이 겹치는 종목 N개」 — 세 화면을 사람이 오가며 맞추던 것을 서버가 교집합으로. 재료는 전부 있음 |
| 3 | **종가배팅 조건 노화 경고** | 중 | 전체 vs 최근 20일 초과수익이 1%p 이상 벌어지면 서버가 「조건이 시장과 어긋나기 시작했다」 경고 생성 — 지금은 사람이 눈으로 비교 |
| 4 | **수출↔업종 어긋남 경고** | 소 | exportYoyForSector 로 「수출 2개월 연속 YoY 마이너스인데 업종 지수는 상승」을 맥박 risks 에 추가. 함수는 이미 있고 연결만 |
| 5 | **다이버전스 10일 창 추가** | 소 | 5일 고정 → 5일·10일 둘 다. 데이터 20일 쌓인 뒤 켜지게 |
| 6 | **일정 매매 반자동 입력** | 대 | 캘린더 이미지 인식 결과에서 「일정 매매에 넣기」 버튼 — 입력 끊김 방지 |

추천 순서: **1(오늘 가능, 정직함 문제) → 4(연결만) → 2 → 3**. 5·6은 데이터/시간이
쌓인 뒤.
