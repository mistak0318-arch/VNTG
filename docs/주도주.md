# 주도주 — 단독 메뉴 (2026-09-08)

벤티지: "마켓브리핑의 주도주 탐색, 좀만 더 손보면 단독 메뉴로도 쓸 수 있을 것 같은데. 거래량급증·신고가·급등·대금상위 카드도 정보를 더 넣고, 걸린 종목엔 마크가 안 붙네."

## 무엇이 바뀌었나

| 자리 | 전 | 후 |
|---|---|---|
| 메뉴 | 마켓브리핑 안 탭 | 시황 그룹 넷째 메뉴 「🏁 주도주」. 브리핑 탭은 길잡이 + 같은 패널 |
| 탭 | 한 장 | 오늘 · 판의 흐름 · 조용한 후보 · 성적 |
| 태그 | 이름만 | 숫자 붙음 — 「거래량 3.2배」「250일 신고가」「+7.4%」「대금 2,100억」, 툴팁에 문턱 (`tagDetail`) |
| 태그 카드 | 없음 | 넷 — 오늘 몇, 초록 몇, 어느 섹터, 대표 셋. 누르면 표가 그 태그로 걸러짐. 아래 한 줄 읽는 법(신고가 ≥ 급등 → 추세장 / 급등 ≫ 신고가 → 뜨거운 날) |
| 걸린 종목 표 | 이름만 | ★ · 🌟⚡🌈 · 신호등 점(원장에 있을 때만, 없으면 ·) · 🔥⏳ · 오늘 처음이면 N. 경보 붙은 줄은 흐리게 |
| 섹터 카드 | 폭·연속·유지 | + 「어제 폭 → 오늘 폭 ↗↘」 + 「N일째」 |
| 갱신 | 손으로 | 장중(09:00~15:40) 10분마다 + 머리에 갱신 시각·「오늘 처음 걸린 것 N」 |

## 판의 흐름 (`/api/pulse/leaders/flow?days=`)
15:35 기록(`data/leaderScan.json` `days[]`)으로 날짜 × 섹터 격자. 칸 = 그날 상위에 든 날, 값·색 = 폭(09-08부터 `sectorStats` 기록, 그 전은 ●). 가로: 이어지나 / 세로: 어제와 같은 판인가(맨 아래 「어제와 같은 판 %」). 오늘 상위 + 사흘째면 굵게.

## 조용한 후보 (`LeaderScan.quiet`)
폭 60% 넘는 섹터의 구성원(거래대금 상위 200 안) 중 오늘 +3% 미만 · -3% 위 · 신고가 아님 · 거래량 2배 미만 · 걸린 종목 아님. 줄마다 판 폭·판 며칠째·오늘·5일선 이격(일봉 파일)·거래대금·표식. 정렬: 판 폭 → 신호등 있는 것 → 이격 작은 순. 「살 것」이 아니라 「볼 것」 — 사려면 항해일지 체·자리 조건을 그대로 지난다. 15:35 기록에 `quiet` 도 남겨 다음 달부터 뜨거운 쪽과 5·20일 성적을 나란히 낸다.

## 표식은 조회 0회
`superSignal.superMarkIndex()`(슈퍼·무지개·교차·경보) + `listTrack.activeListEntries()`(신호등 원장 점수). 원장에 없는 종목의 신호등은 null = 「안 잼」. 거짓 초록을 안 만든다. `leaderScan` 은 이 둘을 지연 import 한다(순환).

## 안 한 것
텔레그램 알림(15:35 기록은 이미 있음, 벤티지가 원할 때). 태그 카드의 「5일 뒤 평균·승률」은 성적 탭 값을 넘길 자리(`track` prop)만 두고 아직 안 이었다 — 성적은 종목마다 일봉을 받아 몇 십 초라 카드가 그걸 기다리면 안 된다.
