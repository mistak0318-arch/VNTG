# 텔레그램 방 구성 가이드

> 2026-08-26 기준. 발송 지점이 늘면 이 문서와 `web/src/components/TelegramOverviewPanel.tsx` 의 표를 같이 고친다.

## 지금 무엇이 나가고 있나 (전수)

봇은 하나, 방(chat_id)은 갈래별로 나눌 수 있다. 서버 `telegram.ts` 가 6개 갈래를 지원한다.

| 갈래 | 보내는 것 | 빈도 | .env 키 |
|---|---|---|---|
| `report` | 데일리 리포트 (조간·장중·석간) | 하루 3건 | `TELEGRAM_CHAT_ID_REPORT` |
| `signal` | 관심종목 시그널 + VI·체결강도 + 손절 감시 | 장중 0~수십 건 | `TELEGRAM_CHAT_ID_SIGNAL` |
| `channel` | 채널 AI 정리(07/12/18시) + 선별 자동발송(건별) | 하루 수십 건 | `TELEGRAM_CHAT_ID_CHANNEL` |
| `disclosure` | 공시 알림 (켰을 때) | 하루 0~수 건 | `TELEGRAM_CHAT_ID_DISCLOSURE` |
| `keyword` | 키워드 알림 (켰을 때) | 하루 0~수십 건 | `TELEGRAM_CHAT_ID_KEYWORD` |
| `super` | 슈퍼신호등 편입·이탈(15:45) + **슈퍼 종목의** 시그널·VI·공시·키워드 | 하루 0~수십 건 | `TELEGRAM_CHAT_ID_SUPER` |
| `log` | (예약 — 현재 보내는 코드 없음) | - | `TELEGRAM_CHAT_ID_LOG` |

키를 비워 두면 그 갈래는 기본 방 `TELEGRAM_CHAT_ID` 로 떨어진다. 방을 안 나눠도 동작은 한다 — 나누는 건 **읽는 사람 편의**다.

## 왜 나누나 — 권장 구성

알림의 생명은 「울리면 반드시 본다」다. 성격이 다른 게 한 방에 섞이면 급한 것이 묻히고, 결국 방 전체를 안 보게 된다.

권장 5방 (+기본 1방):

1. **시그널 방** (`SIGNAL`) — 알림 소리 **켬**. 급한 것만 온다: 시그널·VI·손절. 여기 울리면 본다.
2. **리포트 방** (`REPORT`) — 알림 소리 취향대로. 하루 3건 정기.
3. **채널 수집 방** (`CHANNEL`) — 알림 소리 **끔** 추천. 건수가 가장 많다(선별 자동발송). 시간 날 때 훑는 방.
4. **공시 방** (`DISCLOSURE`) — 알림 켬. 내 종목 공시는 놓치면 안 된다.
5. **키워드 방** (`KEYWORD`) — 취향대로. 채널발이라 소음이 섞일 수 있다.
6. **슈퍼신호등 방** (`SUPER`) — 알림 켬 추천. 이 방을 만들면 **슈퍼 종목의 모든 이벤트가
   여기로 모인다**: 편입·이탈(15:45), 그리고 시그널·VI·공시·키워드 알림 중 슈퍼 종목 건.
   방이 없으면 각 알림은 원래 갈래로 간다 (편입·이탈만 시그널 방으로).
- 기본 방(`TELEGRAM_CHAT_ID`)은 안전망 — 키를 빼먹은 갈래가 여기로 온다.

## 방 만들고 연결하는 순서

1. 텔레그램에서 **새 그룹**을 만든다 (나 혼자 + 봇이면 된다).
2. 그룹에 **봇을 초대**한다 (봇 이름으로 검색 → 멤버 추가).
3. 그룹에 아무 메시지나 하나 보낸 뒤, 브라우저에서
   `https://api.telegram.org/bot<봇토큰>/getUpdates`
   를 열어 `"chat":{"id":-100xxxxxxxxxx,...}` 의 **id 값**(음수)을 읽는다.
   ※ 아무것도 안 나오면 그룹에 메시지를 한 번 더 보내고 새로고침.
4. 미니PC `C:\vntg-hts\server\.env` 에 해당 키로 적는다:
   `TELEGRAM_CHAT_ID_SIGNAL=-100xxxxxxxxxx`
5. **서버 재시작** (.env 는 시작할 때 읽는다).
6. 설정 > 발행·알림 > 「텔레그램 발송 한눈에」에서 방 배정이 "전용 방"으로 바뀌었는지 확인.

## 주의

- chat_id 는 비밀번호는 아니지만 굳이 공개할 값도 아니다 — .env 밖으로 꺼내지 않는다.
- 봇 토큰·텔레그램 세션 문자열은 **절대** 채팅·커밋에 붙여넣지 않는다.
- 같은 chat_id 를 두 키에 적으면 두 갈래가 한 방에 섞인다 — 「한눈에」 표가 "다른 갈래와 같은 방"이라고 알려준다.
