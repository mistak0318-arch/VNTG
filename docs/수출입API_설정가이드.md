# 수출입 무역통계 API 설정 가이드

작성: 2026-08-14 · 공공데이터포털에서 실제 확인한 내용

---

## 왜 이 데이터인가

**반도체·자동차·석유화학 수출 증감률은 해당 섹터 실적의 선행 지표다.**
분기 실적은 이미 주가에 반영된 뒤에 나오지만, 관세청은 **10일 단위 잠정치**를 낸다.

| 구간 | 공표일 |
|---|---|
| 1일~10일 | 11일 |
| 1일~20일 | 21일 |
| 1일~말일 | 익월 1일 |

**월 3회 갱신**이라 방향 전환을 훨씬 빨리 읽을 수 있다.
품목 구분은 반도체 · 원유 · 기계류 · 가스 · 반도체장비 · 정밀기기 · 석유제품 ·
무선통신기기 · 승용차 · 석탄 (단위: 천 달러).

---

## 1단계 — 공공데이터포털 가입

https://www.data.go.kr

회원가입에 **본인 인증이 필요하다.** 이건 대신 해줄 수 없으니 직접 하셔야 한다.

---

## 2단계 — 활용신청

로그인 후 아래 API를 검색해서 **활용신청** 버튼을 누른다.

| 우선순위 | API 이름 | 데이터셋 ID | 왜 |
|---|---|---|---|
| ★ 1 | 관세청_수입 주요품목별 10일 단위 잠정치 통계 | `15157901` | **가장 빠른 신호.** 월 3회 갱신 |
| ★ 2 | 관세청_품목별 수출입실적(GW) | `15101609` | HS코드 2·4·6·10자리별 수출입. 업종 매핑의 기준 |
| 3 | 관세청_국가별 수출입실적(GW) | `15101612` | 대중국·대미 수출 비중 변화 |
| 4 | 관세청_품목별 국가별 수출입실적(GW) | `15100475` | 품목×국가 교차. 가장 상세하지만 호출량이 크다 |

직접 링크:
- https://www.data.go.kr/data/15157901/openapi.do
- https://www.data.go.kr/data/15101609/openapi.do

### 신청할 때 알아둘 것

- **개발계정은 자동승인이다.** 신청 즉시 키가 나온다 (심의 없음).
- **일 10,000건.** 우리는 하루 3~4회 부르면 충분하니 넉넉하다.
- 운영계정으로 올리려면 활용사례 등록 + 심의가 필요한데, 개인 사용에는 불필요하다.
- 무료. 이용허락범위 제한 없음.

> ⚠️ **수출 10일 단위 API는 아직 못 찾았다.**
> 수입 쪽(`15157901`)은 확인했는데 수출 대응 API가 공공데이터포털 검색에 안 잡힌다.
> 로그인 후 포털에서 "수출 10일" 로 다시 검색해 보고, 없으면
> `관세청_품목별 수출입실적(GW)`(`15101609`)으로 수출을 받아야 한다.
> 이쪽은 갱신이 느릴 수 있으니 실제 갱신 주기를 확인할 것.

## 3단계 — 키를 .env에 넣기

승인되면 마이페이지 → 개발계정 상세보기에서 **일반 인증키(Encoding / Decoding)** 두 가지가 나온다.

```
DATA_GO_KR_KEY=<Decoding 키>
```

> **Encoding 키가 아니라 Decoding 키를 넣는다.**
> 우리 코드가 `URLSearchParams`로 인코딩하기 때문에, 이미 인코딩된 키를 넣으면
> 이중 인코딩돼서 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` 가 난다.
> 이게 이 API에서 제일 흔한 실패다.

미니PC(`C:\vntg-hts\server\.env`)에도 같은 줄을 넣어야 실제 리포트에 반영된다.

---

## 4단계 — 스펙 확인

**공공데이터포털 문서 페이지에는 엔드포인트와 파라미터가 안 적혀 있다.**
승인 후에 나오는 Swagger 또는 첨부된 기술문서(.docx)를 봐야 정확한 값을 알 수 있다.

키를 넣고 아래를 실행하면 실제 응답을 받아서 스펙을 뽑아준다:

```
cd server
node scripts/trade-probe.mjs
```

여러 후보 엔드포인트를 순서대로 찔러보고, 성공한 것의 **실제 응답 필드 목록**을 출력한다.
그 결과를 알려주면 수집 모듈을 붙인다.

전부 실패하면 포털에서 받은 기술문서의 엔드포인트를 인자로 넘길 수 있다:

```
node scripts/trade-probe.mjs "https://apis.data.go.kr/1220000/..."
```

## 붙일 자리 (스펙 확인 후)

1. **데일리 리포트 "수출 동향" 섹션** — 10일 단위 잠정치의 전년 동기 대비 증감률
2. **섹터 강세 판정 보조근거** — 반도체 수출이 꺾이는데 반도체 업종만 오르면 경고
3. **신호등 항목 추가** — "소속 업종 수출 증가"

### 선행 과제: HS코드 ↔ 키움 업종분류 매핑

이게 제일 손이 많이 간다. 10일 단위 API는 품목명이 이미 한글로 오므로
(반도체·승용차 등) 그건 바로 매핑되지만, `품목별 수출입실적(GW)`은 HS코드로 오기 때문에
2자리(류) 기준으로 키움 업종에 대응시키는 표가 필요하다.

초안은 `server/src/tradeMapping.ts` 참고.
