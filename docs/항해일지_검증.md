# 항해일지 — 체결 검증 도장과 장부 자가점검 (2026-09-07 밤)

벤티지: "항해일지 오늘 매수했는데 체결 내역도 안 나오고 이상하네. 매수 매도 검증 로직도 손보고, 너라면 어떻게 구현하라고 했을까 프롬프트 하나 써 보고 그대로 구현해."

## 시스가 스스로에게 준 프롬프트

> 항해일지는 지금 「기록되면 끝」인 장부다. 사고 팔면 `fills` 에 한 줄 밀어 넣고 `positions` 와 `cash` 를 고치는데,
> 그 둘이 서로 맞는지 아무도 안 본다. 화면은 실패를 삼키고(「아직 체결이 없습니다」), 한 번 읽고 끝이라 장중에 산 게 안 보인다.
> 이걸 **검증되고 맞춰지는 장부**로 바꿔라.
>
> 1. **체결 도장.** 살 때·팔 때마다 그 체결에 `verify:{ok, notes, seen}` 을 남긴다. 검증은 기록만 하고 매매를 막지 않는다(모의 장부다).
>    - 가격: 그날 고저 안(KRX+NXT 통합 일봉 — 항해일지가 사는 값이 `_AL` 이다) · 전일 종가 ±15% · 시가배팅은 통합 시가 ±2% · 종가배팅은 통합 종가 ±2%
>    - 매도: 손절이면 그날 저가가 손절가에 닿았어야 한다 · 손절가보다 3% 넘게 낮게 팔렸으면 슬리피지 과다
>    - 수량: 같은 날·같은 슬롯·같은 종목 두 번 금지 · 수량·가격 0 금지 · 종목 비중은 `maxPerStock` 안
>    - 시장: 신호등 빨강·공포 국면에 매수면 도장 실패
> 2. **장부 자가점검.** `positions`·`cash`·`misu`·`credit` 을 `fills` 만으로 다시 만들어 장부와 비교한다. 수량·예수금·없는 포지션이 어긋나면 ✕, 평단·산 날·일지 건수·도장은 △.
>    저녁 일지를 쓴 뒤 자동으로 한 번 재고, ✕ 가 있으면 텔레그램 로그 방으로 하루 한 번 알린다.
> 3. **화면.** 매매일지 탭은 오류를 오류로 보이고, 30초마다 다시 읽고, 「오늘 N건」을 맨 위에 따로 센다. 오늘 계획했는데 원장에 없는 매수는 빨간 상자로 따로.
>    도장 실패는 빨간 줄 + 이유. 도장 없는 옛 체결은 버튼으로 30건씩 뒤늦게 찍는다. 계좌 탭엔 「장부 점검」 카드.

## 실측 (삼성전자 2026-09-04, 통합 일봉 시 251,000 / 고 259,000 / 저 251,000 / 종 255,500)

- 범위 안 매수 → 통과
- 고가 위 체결 → 「고가 위」「전일 종가 15% 벗어남」 실패
- 시가배팅인데 시가 +3% → 실패
- 손절 매도인데 저가가 손절가에 안 닿음 → 실패
- 같은 날·슬롯 중복 매수 → 실패
- 재구성: 10주 매수·4주 매도 → 6주 평단 70,011 · 현금 39,587,334

주의: KRX 단독 일봉(시 254,000 / 저 252,500)과 통합 일봉이 다르다. 항해일지는 통합 값으로 사니 통합 일봉으로 재는 게 맞다.

## 「오늘 매수했는데 체결이 안 보인다」에 대해

로컬엔 원장이 비어 있어 미니PC 의 그날을 재현할 수 없었다. 가능성은 셋이고 이제 셋 다 화면에서 갈린다.

1. `/api/cis/fills` 가 실패했는데 화면이 삼켰다 → 이제 오류 배너.
2. 원장엔 있는데 화면이 한 번 읽고 안 바꿨다 → 30초 재읽기 + 「오늘 N건」.
3. 일지엔 「계획」이 있는데 `buy()` 가 거절(여력·수량 0)했거나 저장 전에 끊겼다 → 「계획했는데 원장에 없는 매수」 상자 + 장부 점검.

## 근거 줄 · 장중 일기 · 원리 패널 (2026-09-08)

벤티지: "각각에 매수 근거·매도 근거 이유 붙여 주고, 장중에 일기 쓰는 것도 보완해 줘. 각각의 탭에 해당 알고리즘의 원리도."

- **`Fill.basis: string[]`** — 매수: `시장 · 종목 · 자리 · 계획 · 비중 (· AI)`, 매도: `규칙 · 산 값 · 계획선 · 흔들림 · 살 때 이유 · 언제`. `cisTrader.sellBasis(e)`, 매수는 `buyRound`/`closeBetRound`/연금에서 줄을 만든다. 매매일지 탭 근거 칸에 「매수 근거 ▸ / 매도 근거 ▸」.
- **장중 일기 `CisDay.intraday`** — `cisJournal.addIntraday`. 1분 감시의 매도·본전 전환, 15분 스캔은 **안 샀어도** 한 줄(시장 문·체에 걸린 것·자리 조건 미달·통과·계획·샀다), 09:05·10·11·13·14·15시·15:20 상태 한 줄(종목별 수익률·손절선까지 거리·평가액). 오늘 탭 아침 다음에 「장중」 칸, 스캔은 접혀 있고 마지막 것만 요약.
- **원리 패널** — 계좌 머리에 「이 계좌는 이렇게 돈다」 접이식. 값은 `config.rules`·`times`·`pensionDays` 를 그대로 읽어 글과 코드가 안 갈린다. 단기 추세 / 종배 / 연금(개인·퇴직) 셋으로 갈린다.
