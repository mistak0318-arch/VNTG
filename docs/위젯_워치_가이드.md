# 위젯 · 워치 빌드 가이드

> 2026-08-26 작성. 소스는 `android/` 폴더 — 폰 앱(바탕화면 위젯) + 워치 앱 두 모듈.
> 참고 화면(TODO G절): **위젯 = 증권플러스 모양, 워치 = 네이버 증권 워치앱 모양.**

## 무엇이 들어 있나

| 모듈 | 내용 |
|---|---|
| `app` | 바탕화면 **위젯**(Glance) — 관심종목 세로 목록. 한 줄 = 종목명·현재가·대비·등락률·거래량. **크기 조절하면 칸이 준다**(좁으면 거래량→대비 순으로 뺌). ⚙에서 서버 주소·Access 토큰·그룹 선택. 15분 자동 갱신 + ↻ 즉시 갱신. 앱 아이콘을 누르면 웹(HTS)이 열린다 |
| `wear` | **워치 앱**(Wear OS 3+, standalone — 폰 없이 동작). 목록 = 해외 카드(티커·현재가·등락률·After/Day 세션가) + 국내 관심 + 지수·신호등. 카드 누르면 상세 |

서버 쪽은 이미 구현·배포되어 있다:
- `GET /api/summary/widget?group=` — 위젯 한 장 JSON (그룹·기준시각·장 구분·줄 목록·지수·신호등)
- `GET /api/summary/watch` — 워치 한 장 JSON (국내 8 + 해외 12 + 세션가)
- `GET /api/summary/groups` — 위젯 설정의 그룹 목록

⚠️ 시세는 통합(_AL)이다. **마감 후 통합 현재가는 NXT 애프터 값** — 그래서 응답의
`venue`(정규장/NXT 애프터마켓/마감…)를 위젯·워치가 그대로 표기한다.

## 빌드 (개발 PC엔 안드로이드 SDK가 없어서 여기선 못 한다)

1. **Android Studio 설치** (https://developer.android.com/studio) — SDK·JDK가 같이 온다.
2. Android Studio → Open → `android/` 폴더 선택. 첫 sync 때 Gradle wrapper·SDK 를 알아서 받는다.
   (버전 충돌이 뜨면 Studio가 제안하는 버전 업데이트를 그대로 수락하면 된다)
3. 위젯(폰): 상단 모듈 선택을 `app` 으로 → 폰을 USB 연결(개발자 모드) → Run.
   설치 후 홈 화면 길게 눌러 위젯 추가 → "VNTG 관심종목".
4. 워치: 모듈 `wear` → 워치를 무선 디버깅으로 페어링([설정>개발자옵션>무선 디버깅]) → Run.
   **빌드 전에 `wear/src/main/res/values/config.xml` 에 서버 주소·토큰을 적는다**
   (워치에서 타이핑은 고문이라 빌드에 박는다).

## Cloudflare Access 서비스 토큰 (vntgts.com 으로 쓸 때)

위젯·워치는 브라우저가 없어서 Access 로그인 화면을 못 지나간다. **서비스 토큰**으로 통과한다.

1. Cloudflare Zero Trust → Access → **Service Auth** → Create Service Token
   → 이름 "vntg-widget", 만료는 짧게(1년 이하). **Client ID / Client Secret** 를 받아 둔다.
2. Access → Applications 에서 **새 애플리케이션** 하나를 만든다:
   - 경로: `vntgts.com/api/summary/*` **만** (조회 요약 전용 — 계좌·설정 경로는 이 토큰으로 못 들어온다)
   - 정책: Action **Service Auth** → Include: Service Token = 방금 만든 토큰
3. 위젯 ⚙ 설정(또는 워치 config.xml)에 Client ID/Secret 를 넣는다.
4. ⚠️ 시크릿이 기기에 박힌다 — 폰을 바꾸거나 잃어버리면 **토큰을 폐기하고 새로 판다.**

집 안 내부망(미니PC 직결 `http://192.168.x.x:포트`)으로만 쓸 거면 토큰 없이 주소만 넣으면 된다.
