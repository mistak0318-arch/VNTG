**① API 제공 범위 확인 (제일 먼저 실행)**

```
현재 프로젝트는 키움 REST API를 Node.js로 호출하는 구조야.
개별 종목의 투자자별 세부 수급은 이미 정상적으로 가져오고 있어.

키움 REST API 공식 문서와 현재 코드베이스를 확인해서 아래 4가지가
제공되는지, 제공된다면 TR명/엔드포인트/요청 파라미터/응답 필드명을
정리해서 알려줘. 코드는 아직 작성하지 말고 조사 결과만 보고해줘.

1. 코스피/코스닥 "시장 전체" 투자자별 순매수 집계
   - 종목별 조회를 합산하는 방식 말고, 시장 단위로 한 번에 주는 TR이 있는지
   - 없다면 대안이 뭔지도 같이 알려줘

2. 기관 세부 구분 제공 여부
   - 금융투자 / 투신 / 연기금 / 사모펀드가 각각 분리되어 나오는지
   - 응답 필드명과 코드값 매핑

3. 선물 투자자별 매매동향
   - 주식과 별개인 파생 카테고리 TR로 찾아볼 것
   - 코스피200 선물 기준 투자자별 순매수

4. 등락률 순위 / 상한가·하한가 종목 조회
   - 상승, 하락, 상한가, 하한가 각각의 TR
   - 정렬 기준과 조회 건수 제한

추가로 확인해줄 것:
- 각 TR의 rate limit (초당/분당 호출 제한)
- 수급 데이터 갱신 주기 (실시간인지 지연인지)
```
