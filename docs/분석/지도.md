## 4. 도는 것 — 스케줄러 25개

`index.ts` 가 뜨면서 켜는 것들. **이 시스템은 요청이 없어도 계속 돈다.**

```
리포트 · 스냅샷 · 추적 · 알림 · 장세 · 항해일지 · 시뮬 · 항해일지 장중감시
채널 · 메이저피드 · 버즈 · 뉴스키워드 · 캘린더 · 보관 · ETF보유 · 시스
테마 · 일봉 · 백테스트그리드 · 주도주 · 종가배팅 · 실시간 · 거래원 · 마감뒤 · 주문점검
```

25개가 각자 타이머를 갖고 있다. **서로 순서를 모른다** — 예외가 `afterClose`(마감 뒤
파이프라인)인데, 그건 「시각이 아니라 차례」로 고친 자리다. 나머지 24개는 시각으로 돌고,
그래서 앞 작업이 안 끝나도 다음이 돈다. ②회차에서 볼 위험 지점 중 하나다.

## 5. 화면 (웹)

- 진입점 `main.tsx` → `App.tsx`
- **탭 39개** (`Tab` 유니온), 사이드바 메뉴로 진입
- 모든 데이터는 `api.ts` 하나를 지난다 (183파일이 import)
- 라우팅은 해시 하나 (`useHashRoute`) — `#/{tab}?code=&name=`
  - ⚠️ **이 라우터는 `code`/`name` 말고 다른 파라미터를 버린다.** 주문 화면이 `stk` 라는
    딴 이름을 쓰고 모듈 변수로 값을 훔쳐 두는 우회를 하는 이유가 이것이다.
    ②회차에서 다시 볼 자리.

## 6. ①회차에서 이미 나온 것

### 죽은 파일 5개 — 772줄

아무도 import 하지 않고 문자열로도 안 불린다.

| 파일 | 줄 |
|---|---:|
| `server/src/sectorPer.ts` | 135 |
| `server/src/tradeMapping.ts` | 110 |
| `web/src/components/CumulativeRank.tsx` | 222 |
| `web/src/components/IndexIntraday.tsx` | 155 |
| `web/src/components/ThemeDbPanel.tsx` | 150 |

`topicPulse.ts`(287줄)는 **살아 있다** — `await import()` 로만 불려서 정적 그래프에
안 잡혔다. 지도를 만들 때 처음 잘못 짚었고, 확인해서 고쳤다. **동적 import 20곳이
그래프에 안 보인다**는 사실 자체를 여기 적어 둔다.

### 구조적으로 봐 둘 자리

1. **`api.ts` 6,594줄이 183파일에 물려 있다.** 타입과 호출이 한 파일에 다 있다.
   고칠 때마다 전부가 다시 컴파일되고, 서버 타입과 손으로 맞춘 것이라 **어긋나면 조용하다**
   (오늘 실제로 `TelegramChannelStatus` 에 `order` 가 빠져 있었다).
2. **스케줄러 25개가 서로를 모른다.** 마감 뒤 파이프라인만 차례로 고쳤다.
3. **해시 라우터가 파라미터를 버린다.** 우회가 이미 하나 있다(`stk`).
4. **신호등이 서버의 5분의 1인데 세 갈래가 그것을 쓴다.** 값 하나가 셋을 움직인다.
