## 방법

「전일 대비」·「현재가」·「거래대금」이 계산되는 자리를 `grep` 으로 모으니 387곳·90파일이라 전부
읽지 않았다. 대신 **한 화면에 나란히 뜨는 값**을 골라 각각의 **기준(base)** 을 추적했다.
우선순위는 의뢰서대로 — 돈 → 판단 → 조용히 빈 것 → 보기 불편.

## 지금 이 저장소에 없는 안전장치 — 값싼 것부터 셋

1. **「전일」의 단일 출처.** `prevCloseOf(code, venue)` 같은 함수 하나가 base 를 내고, 등락률을 계산하는 모든 자리가 그것만 부르게. 지금은 출처마다 제각각이라(한투 ctrt · 직전 봉 · base_pric · 전일종가 역산) 항목 1·4 같은 것이 계속 난다. **가장 값싸고 가장 넓게 막는다.**
2. **한 화면 두 값 검산.** 같은 개념이 한 화면에 두 번 뜨는 자리(야간선물 헤더+카드, 시세분석 칸+봉)에서 **두 base 가 다르면 콘솔 경고 + 작은 ⚠️ 툴팁**. 고치지 않아도 어긋남이 **보인다**.
3. **`server/tools/consistencyCheck.ts`.** 종목 하나를 골라 상세 헤더·시세분석 한 줄·계좌 평가가 내는 현재가·등락률·거래대금을 **한 번에 찍어 나란히** 놓는 도구. 키움 조회 3~4건이라 장중 아닐 때 돌린다. 오늘 항목 1·2·3 은 이 도구 하나면 30초에 드러났다.
