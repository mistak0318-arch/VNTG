- **키움 `ka10001` 은 새벽 6시쯤 이미 새 날로 넘어간다**(시가·거래량 0) — 07:50 까지는 일봉 마지막 거래일로 채운다(`dawnPrice`)
- **야후 선물·VIX·코인 일봉은 뉴욕 자정(한국 13:00)에 찍혀 24시간을 간다.** 「12시간 전 봉 = 전일」은 틀린다 — 지금 값이 든 봉의 앞 봉이 전일
- **네이버 증권은 `m.stock.naver.com/api/...` JSON 이다**(9/15 이사). 옛 `finance.naver.com/sise` HTML 은 302 로 튕긴다
- **신호등 분석(`runListTrack`)을 하루 두 번 돌리지 말 것** — 이어진 날(`seenCount`)이 둘씩 는다. 종배가 일찍 필요하면 `closeBetScan`

**검증**
- **야후 `5y` 는 주봉이다.** 일봉이 필요하면 `2y`
- **벤치마크 없는 승률은 아무것도 증명하지 못한다.** 시장이 오른 몫과 종목을 고른 몫을 가를 것
- **문턱을 올리면 좋아 보이지만 표본이 녹는다** · **생존편향** — 지금 고른 종목의 과거만 본다
- **숫자 단위는 문서가 아니라 곱해서 아는 값과 맞춰** 본다(한투 추정 EPS 가 10배였다)
- **키움 평가손익(`evltv_prft`)엔 비용이 이미 빠져 있다** — 또 빼면 두 번 빠진다

**시세·시각**
- **한투 `last` 는 미국 정규장 마감 후 애프터장 값이다** · 한투 `price-detail` 은 종목명·등락률을 안 준다
- **실시간 갱신은 `state === "open"` 이 아니라 `live` 를 본다**
- **키움 제한은 TR 하나당 초당 5건**
- **시각은 PowerShell `Get-Date` 로 본다** — Git Bash `date` 는 UTC 다

**화면**
- `.rp-pinned-body` 의 `white-space: pre-wrap` 을 지우지 말 것 · `TrendLineChart`·`Sparkline` 은 선으로 둔다(확정)
- 「미국↔국내」 탭은 숨겨 뒀다(주석 한 줄) · 네이버는 조회수를 안 준다(「이슈화」는 매체 수)
