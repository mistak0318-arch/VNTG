# 📰 뉴스레터 기능 (2026-08-13 요청) — 텔레그램과 함께 최우선

인포스탁 주식신문 같은 형식의 리포트를 **하루 3회** 사용자 네이버 메일로 발송.

## ⚠ 먼저 확인할 것 — 인포스탁 크롤링은 하지 않는다

인포스탁은 **유료 구독 서비스**이고, 페이지에 이렇게 명시돼 있다:

> "본 주식신문은 인포스탁 유료회원에게 제공되는 정보이며, 본 컨텐츠를 캡쳐하여
> 온라인상에 게시하거나 공유하는 행위는 저작권법 위반으로 고발조치 됩니다."

따라서 **인포스탁 내용을 긁어와 재배포하는 방식은 구현하지 않는다.**
개인 메일로 보내는 것도 재배포에 해당한다.

**대신 같은 목적을 합법적으로 달성한다** — 형식·구성은 참고하되,
데이터는 우리가 이미 쓰고 있는 정식 소스에서 직접 모아 **자체 리포트**를 만든다.
형식(목차 구성, 섹션 배열)은 저작권 대상이 아니므로 비슷하게 꾸며도 된다.

## Claude API 활용 (결제 완료됨)

- 뉴스 제목 수십 건 → **핵심 이슈 3~5줄로 요약**
- 테마 등락 데이터 → **"오늘 왜 올랐나" 한 문단**
- 토큰 절약: 원문 전체를 넣지 말고 **제목 + 등락률 숫자만** 전달
- 모델: `claude-sonnet-5` (요약 용도엔 충분). 비용 민감하면 `claude-haiku-4-5-20251001`
- 실패해도 메일은 나가야 함 → 요약 실패 시 원본 데이터만 넣어 발송

## 메일 발송 — 네이버 SMTP

```

포트: 465 (SSL)
계정: 네이버 아이디 / 비밀번호
```
- ⚠ 네이버 메일 설정에서 **POP3/SMTP 사용 '사용함'** 으로 먼저 켜야 함
- `nodemailer` 사용 (의존성 1개 추가)
- `.env`에 `NAVER_MAIL_USER`, `NAVER_MAIL_PASS`, `MAIL_TO` 추가
- **비밀번호는 사용자가 직접 .env에 입력한다** (Claude가 대신 입력하지 않음)

## 구현 순서

1. `server/src/mailer.ts` — nodemailer + 네이버 SMTP, `POST /api/mail/test`로 **테스트 메일부터 성공**
2. `server/src/report.ts` — 섹션별 데이터 수집 → HTML 조립 (인포스탁처럼 표 중심)

5. 설정 화면에서 on/off, 수신 주소, 테스트 발송 버튼

> 텔레그램 봇의 스케줄러·설정 저장 구조를 그대로 재사용한다.
> **텔레그램을 먼저 만들고 뉴스레터를 얹는 순서가 효율적이다.**

## 주의

## anthropic은 특별 취급

- 설정 화면에 **누적 토큰 + 추정 비용(모델별 단가 × 토큰)** 표시

  안전장치를 고려 (무한 과금 방지)

## 구현 위치
- `apiUsage.ts` — provider 정의 + 토큰 누적 필드 추가
- `summarize.ts` — Claude 호출 후 `recordApiCall("anthropic", model, "ok", {inputTokens, outputTokens})`
- `SettingsPage.tsx` — 카드 3개 추가, anthropic 카드엔 토큰/비용 표시

# 🆕 추가 기능 요청 (2026-08-13)

사용자가 정리해 준 5개 항목. **실현 가능성 판단을 각 항목에 붙여둠.**

## 1. HTTPS 전환 — ✅ 가능 (Tailscale 경유에 한해)

**현재 상태 정정**: Tailscale 주소(`100.x.x.x`)로 접속할 때는 겉보기만 HTTP이고
실제 트래픽은 **WireGuard로 암호화**된다. 이미 도청 위험은 없다.

그래도 진짜 HTTPS를 원하면:
- `tailscale cert` + MagicDNS → **Let's Encrypt 정식 인증서**를 `*.ts.net` 도메인으로 발급 가능.
  브라우저 경고 없이 자물쇠가 뜬다. 이게 정답
- 절차: Tailscale 관리 콘솔에서 MagicDNS + HTTPS 켜기 → `tailscale cert <머신>.<tailnet>.ts.net`
  → Express를 `https.createServer`로 띄우거나 `tailscale serve` 사용
- **LAN 주소(192.168.x.x)는 자체서명뿐** → 브라우저 경고 발생. 굳이 할 필요 없음
- ⚠ **공유기 포트포워딩은 절대 하지 말 것.** 이건 HTTPS 여부와 무관하게 위험

## 2. 캘린더 (마이페이지) — ✅ 가능 / 구글 연동은 △

- **직접 입력 캘린더**: `server/data/calendar.json` + CRUD 라우트 + 월/주 뷰. 어렵지 않음
- **증시 일정 프리셋**: FOMC/CPI/옵션만기/실적시즌 등을 JSON으로 넣어두고 매년 갱신
  (무료 경제캘린더 API가 마땅치 않음. Investing.com은 크롤링 금지)
- **구글 캘린더 연동**:
  - 양방향 동기화(OAuth)는 복잡 — 구글 클라우드 프로젝트 생성, OAuth 동의화면,
    토큰 갱신 처리까지 필요. **권장하지 않음**
  - **대안: iCal(ics) 구독 URL 읽기** — 구글 캘린더의 "비공개 주소(ICAL)"를 `.env`에 넣고
    서버가 주기적으로 파싱해서 읽기 전용으로 표시. **훨씬 간단하고 목적 달성엔 충분**
  - 먼저 iCal 방식으로 하고, 정말 쓰기가 필요하면 그때 OAuth 검토

## 3. 관심종목 그룹 — ✅ 가능 (쉬움)

- 현재 `watchlist.json`은 평면 배열 → `group` 필드 추가
- 종목 추가 시 그룹 선택 드롭다운 (없으면 "기본")
- 그룹 생성/이름변경/삭제, 그룹별 탭 보기
- 기존 데이터는 마이그레이션 시 전부 "기본" 그룹으로

## 4. 테마 / 폰트 설정 — ✅ 가능 (라이트 테마는 손이 좀 감)

- **폰트 크기·글꼴**: `:root`의 `font-size`와 `font-family`만 바꾸면 되므로 쉬움.
  localStorage에 저장
- **라이트 테마**: `styles.css`가 이미 `--bg`, `--panel`, `--text` 등 CSS 변수를 쓰고 있어
  구조는 준비돼 있음. 다만 **하드코딩된 색상이 남아 있는지 전수 점검 필요**
  (특히 차트 컴포넌트 — `CandleChart.tsx`, `TrendLineChart.tsx`에 `#1a232d` 등이 박혀 있음)
- 차트 색상도 테마에 따라 바뀌도록 변수화해야 완성도가 나옴

## 5. 계좌 — 연동 / 수동 분리 — ✅ 가능 (가치 높음)

### 구조
- 계좌 탭을 **"연동 계좌"** / **"수동 계좌"** 로 분리. **통합 자산현황은 만들지 않는다**(사용자 요청)

### 연동 계좌
- 지금 그대로. 키움 API로 잔고·평가손익 자동 조회

### 수동 계좌
- `server/data/manualAccounts.json`
  ```
  { id, broker: "미래에셋", name: "연금저축", holdings: [ { code, name, avgPrice, qty } ] }
  ```
- 증권사 목록은 하드코딩 (미래에셋/삼성/NH/한국투자/KB/신한/토스 등)
- 종목 검색은 기존 `api.searchStocks` 재사용
- **평가금액·손익·수익률은 저장하지 않고 조회 시 계산** — 현재가만 키움에서 가져와
  `(현재가 - 평단) × 수량`. 저장하면 값이 낡는다
- 증권사별 탭 또는 카드 리스트

### 주의
- 이 앱은 **조회 전용**이다. 수동 계좌도 사용자가 직접 적는 메모일 뿐,
  주문·이체 기능은 만들지 않는다
- 시세 조회가 종목 수만큼 발생 → **한 번에 모아서 조회하고 캐싱**할 것 (TR당 초당 5회 제한)
